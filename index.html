Princípios do sistema

O que a Base Comercial é — e o que ela não é
O sistema não é um CRM.
O sistema não dispara e-mails.
O sistema não gerencia leads.
Existe apenas para organizar bases comerciais e gerar listas segmentadas para prospecção.
